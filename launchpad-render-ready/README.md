# Launchpad — AI Mock Interview + Group Discussion (Free-tier setup)

This project preserves the Launchpad dashboard and provides an AI-backed mock interview and a three-person group discussion using the **Google Gemini API free tier**, where available. It is not an HTML-only scripted demo. The backend uses Gemini to create contextual follow-up questions and a final transcript-based evaluation.

## Features

- Spoken interviewer questions using browser speech synthesis.
- Voice answers using browser speech recognition (Chrome/Edge support varies).
- Automatically submits an answer after a short silence and asks the next question.
- Typed answers are also supported and auto-send after a pause.
- No scores during the interview; a detailed report is generated when the candidate ends it.
- Group discussion practice with two AI participants, random topics across IT, marketing, business, and society, three fair turns per participant, and rotating speaker order.
- Distinct illustrated avatars and separate speech-synthesis voices for the two AI participants; voice selection depends on voices available in the browser and operating system.
- AI discussion turns are kept short to reduce generation and playback time; when a model is busy, the discussion route moves directly to the fallback model.
- API key stays on the local server in `.env`, not in the browser HTML.

## Setup on Windows

1. Install Node.js 20 or newer.
2. Extract this ZIP to a folder.
3. Open PowerShell in that folder and run:

   ```powershell
   npm.cmd install
   copy .env.example .env
   ```

4. Open `.env` and paste your API key from [Google AI Studio](https://aistudio.google.com/apikey):

   ```env
   GEMINI_API_KEY=your_actual_key_here
   GEMINI_MODEL=gemini-3.8-flash
   GEMINI_FALLBACK_MODEL=gemini-3.5-flash-lite
   PORT=3000
   ```

5. Start the app:

   ```powershell
   npm.cmd start
   ```

6. Open [http://localhost:3000](http://localhost:3000) in Chrome or Edge and allow microphone access.

## Free-tier and privacy notes

- Google offers free-tier Gemini API access for eligible models/projects, but availability, quotas, rate limits, and terms can change. This project retries transient overloads and uses a configurable fallback model; it cannot bypass exhausted quotas. Check [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing) and [rate limits](https://ai.google.dev/gemini-api/docs/rate-limits) before relying on it. Free use is not unlimited or guaranteed.
- In Google's free tier, submitted content may be used to improve Google products; review the current terms before sending personal information. Avoid entering sensitive information.
- Voice recognition is provided by the browser and may depend on browser support and internet access. If voice recognition is unavailable, type your answer instead.
- AI feedback is a coaching estimate based on the transcript, not a guaranteed factual determination.
- The first opening question is selected by interview type; subsequent questions and the final report are generated by Gemini. Group-discussion turns are also generated by Gemini with the same local API key.

## Troubleshooting

- **GEMINI_API_KEY missing**: make sure `.env` exists in the project root and the key is saved there, then restart the server.
- **401 / invalid key**: create/check the key in Google AI Studio and ensure it was copied correctly.
- **High demand / temporary 429 or 503**: the server automatically retries with short delays, then tries `GEMINI_FALLBACK_MODEL`. Ensure both model IDs are supported by your AI Studio project. If your project does not support the configured fallback, change `GEMINI_FALLBACK_MODEL` in `.env` to a model listed as available in your AI Studio project.
- **Quota exhausted**: retries and fallback cannot bypass an exhausted account/project quota. Check AI Studio rate limits and wait for reset or choose another model with available quota.
- **Microphone doesn't start**: use Chrome/Edge, allow microphone permission, and check Windows microphone privacy settings.
- Keep the terminal open while using the site.
